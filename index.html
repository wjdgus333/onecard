    ⚙️ 로컬룰 설정

    파산 기준손패가 이 장수 이상이면 패배

    기본 규칙

    • 각자 7장으로 시작, 손패를 먼저 다 내면 승리
    • 맨 위 카드와 같은 무늬 또는 같은 숫자를 낼 수 있어요
    • 낼 카드가 없으면 1장 먹기 (낼 수 있어도 먹어도 돼요)
    • 공격: 2 = +2장, A = +3장, 흑백 조커 = +5장, 컬러 조커 = +7장
    • 공격받으면 같은 무늬·숫자이면서 더 세거나 같은 공격 카드로 막을 수 있어요 (공격은 누적!). 못 막으면 쌓인 만큼 먹어요
    • 조커는 아무 때나 낼 수 있고, 조커 뒤에는 아무 카드나 낼 수 있어요
    • J·Q·K: 1대1이라 상대 턴을 건너뛰고 한 번 더
    • 7: 원하는 무늬로 바꾸기
    • 카드가 1장 남으면 원카드! 버튼 싸움 — 늦게 누르면 1장 먹어요. 상대가 1장일 때 먼저 누르면 상대가 먹어요
